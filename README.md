# AppColl

Broadband data collection app with a .NET backend and Angular frontend.

## Setup

Install .NET SDK 10.0+ and Node.js 20+.

## Run

Start the backend:
```bash
dotnet run
```

In another terminal, start the frontend:
```bash
cd ClientApp
npm install
npm start
```

Backend runs on http://localhost:5182, frontend on http://localhost:4200.
